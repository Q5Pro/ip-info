# 🌐 ip-info

IP adresi analiz aracı. Sınıf, özel/genel, CIDR hesaplama.

## Kurulum
```bash
go build -o ip-info .
```
## Kullanım
```bash
ip-info 192.168.1.1
ip-info 10.0.0.0/24
```
